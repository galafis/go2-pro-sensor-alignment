# Contributing · Contribuindo

## English

Start with a reproducible scenario and the expected domain behavior. Change the engine before changing a chart to make an unfavorable result look favorable. Add a known-answer or invariant test for a real behavior change. Run `npm test` and `npm run examples`; update expected reports only after explaining the numerical change. Keep English and Portuguese descriptions aligned. Use synthetic data and do not include participant details, credentials or private project internals.

## Português

Comece com um cenário reproduzível e o comportamento esperado do domínio. Corrija o mecanismo antes de alterar um gráfico para fazer resultado desfavorável parecer favorável. Acrescente teste de resposta conhecida ou invariante para mudanças reais. Execute `npm test` e `npm run examples`; atualize relatórios esperados apenas após explicar a mudança numérica. Mantenha descrições em inglês e português alinhadas. Use dados sintéticos e não inclua detalhes de participantes, credenciais ou informações internas de projetos privados.
