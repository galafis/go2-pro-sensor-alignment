# Security and data handling · Segurança e tratamento dos dados

## English

The workbench analyzes JSON locally in the browser or command-line process. It has no application backend, analytics or automatic scenario upload. Static hosting receives ordinary page requests. The browser stores only language preference automatically; imported text remains in the current page and exports remain on your device. This is not encryption or anonymization. Use coded synthetic examples in public issues. Report sensitive defects privately to gabrieldemetrioslafis@usp.br without sending participant data or credentials.

## Português

A bancada analisa JSON localmente no navegador ou processo de linha de comando. Não possui servidor de aplicação, rastreamento analítico ou envio automático de cenários. A hospedagem estática recebe solicitações normais de página. O navegador armazena automaticamente apenas a preferência de idioma; texto importado permanece na página atual e exportações permanecem no dispositivo. Isso não oferece criptografia ou anonimização. Use exemplos sintéticos codificados em issues públicas. Relate falhas sensíveis de forma privada a gabrieldemetrioslafis@usp.br, sem enviar dados de participantes ou credenciais.
